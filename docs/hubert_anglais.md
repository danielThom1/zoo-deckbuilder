# Hubert en anglais : relecture

*Version anglaise du 18/11/2026.* Chaque réplique française d'Hubert et sa version anglaise, pour vérifier que l'humour passe. Les traductions sont dans `game/lang/en.json` (clé = texte français). Pour changer une phrase anglaise, modifiez sa valeur dans ce fichier.

Choix de traduction : le ton reste celui d'un cadre cynique de grande entreprise (vocabulaire RH et financier anglo-saxon : *restructuring plan*, *quarterly targets*, *synergy*, *agility*). Les jeux de mots français sans équivalent ont été remplacés par une chute de même nature plutôt que traduits mot à mot. Les températures passent en Fahrenheit (42 °C → 108 °F).
